# Voxfolio V25 manual demo runbook

Use a real Supabase project and AssemblyAI key. Never place provider secrets in client code.

- Start with `pnpm dev` on localhost.
- Demonstrate a canonical portfolio, then create an opportunity variant.
- Say: “Go to Opportunity”, then “Focus on AI automation”, then update a fact supplied by the user.
- Show the evidence-aware plan and reject one suggestion before accepting another.
- Edit the canonical source in a second tab, compare it from the variant, and selectively import one update.
- Publish the variant as Shared, create a private link, open it in an incognito window, and submit feedback.
- Return to Studio to show the coarse open count and private feedback.
- Revoke the link and reload the incognito window to show that access is gone.

Record what was actually verified. Do not claim a provider or deployment works unless it was tested with configured credentials.
