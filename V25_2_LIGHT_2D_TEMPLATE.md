# Voxfolio V25.2 — Professional Light 2D template

Added the presentation component and responsive CSS foundation for a light, professional 2D portfolio layout.

The template uses the existing SiteDocument and shared PortfolioNavigation/PortfolioSections renderers. It does not create a second content model or add WebGL.

Integration still requires adding the template ID to the validated template options and routing the public/Studio renderers to `ProfessionalLightPortfolio`. Those changes must be made against the complete current source files so existing migrations and defaults are preserved.
